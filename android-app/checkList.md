# 📋 성경 앱 (BibleReader) 통합 검증 체크리스트

앱의 기능 변경이나 업데이트 발생 전후로, 시각적 일관성과 예외 케이스를 빠짐없이 검증하기 위한 QA(품질 검증) 리스트입니다.

## 1. 시각적 렌더링 및 일관성 (UI/UX)
- [ ] **양쪽 정렬 무결성:** 글자 단위로 매끄럽게 줄바꿈이 이루어지며, 단어 사이나 우측 끝에 비정상적으로 큰 공백 여백이 발생하지 않는가?
- [ ] **하단 여백(Padding):** 텍스트를 가장 아래로 끝까지 스크롤했을 때, 텍스트가 하단 파란색 재생 바에 가려지지 않고 완전히 위로 올라오는가?
- [ ] **하이라이트 UI:** 검색 기능으로 이동한 구절에 옅은 분홍색 하이라이트가 정확히 적용되는가? 
- [ ] **하이라이트 해제:** 재생(▶) 버튼을 누르고 스크롤이 시작되면 하이라이트가 정상적으로 사라지는가?

## 2. 동기화 및 딜레이 로직 (스크롤 & TTS)
- [ ] **검색 후 이동 위치 보정:** 사도행전 7장 20절을 검색하고 이동했을 때, 19절이 아닌 20절이 화면 최상단(여백 포함)에 정확히 위치하는가?
- [ ] **20초 딜레이 (검색 직후):** 검색 기능으로 이동 후 재생 버튼을 눌렀을 때, 스크롤이 20초 동안 대기한 후 시작되는가?
- [ ] **20초 딜레이 (새 장 진입):** 이전 장 낭독이 끝나고 다음 장으로 자동으로 넘어갔을 때, 첫 화면에서 20초 동안 대기하는가?
- [ ] **5초 딜레이 (수동 스크롤):** 재생을 잠시 멈추고 직접 손으로 스크롤을 위아래로 움직인 뒤 다시 재생했을 때, 해당 화면 기준 첫 줄부터 5초 대기 후 읽기 시작하는가?
- [ ] **무한 루프:** 요한계시록 22장 (마지막 장) 끝까지 낭독이 완료되면, 다시 창세기 1장 1절(최초 장)로 스스로 이동하여 재생을 시작하는가?

## 3. 하드코어 예외 케이스 (Edge Cases & Stress Test)
- [ ] **화면 회전 (가로/세로 전환):** 기기를 가로로 눕히거나 세로로 세웠을 때, 앱이 튕기거나 초기화되지 않는가? 
- [ ] **배경 전환 (Background 상태):** 재생 중 홈 버튼을 눌러 앱을 배경으로 내렸을 때, 오디오가 정상적으로 멈추거나 계속 재생되는지 의도된 대로 동작하는가?
- [ ] **매우 긴 장 (예: 시편 119편 - 176절):** 수백 줄이 넘는 긴 장을 열었을 때 앱이 버벅이거나 애니메이션이 비정상적으로 느려지지 않는가?
- [ ] **매우 짧은 장 (예: 시편 117편 - 2절):** 한 화면에 모두 들어오는 짧은 장의 경우, 스크롤 애니메이션이 오류를 일으키지 않고 자연스럽게 다음 장으로 넘어가는가?

## 4. 파싱(Parsing) 및 파일 탐색 무결성
- [ ] **범위 절 검색 (예: 12-13절):** "대상 16장 13절"을 검색했을 때, `12-13`으로 묶인 본문의 정확한 위치로 이동하는가?
- [ ] **제목 괄호 예외:** 절 번호 뒤에 괄호로 설명이 붙은 구절(`<옷니엘이 드빌을 치다(수 15:13-19)>`)이 절 번호로 오작동 파싱되지 않는가?
- [ ] **3단 스피너 ↔ 텍스트 동기화:** 돋보기 창에서 하단 스피너(목록)를 돌렸을 때 상단 텍스트 입력창이 "창 1:5" 등으로 실시간으로 자동 갱신되는가?
- [ ] **외부 파일 가져오기:** 옵션 창에서 사용자가 다운로드한 새로운 `.txt` 파일을 추가했을 때, 앱 메인 상단(제목) 탭 목록에 즉시 반영되는가?
